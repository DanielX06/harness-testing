# Harnesses

Every harness a person made. A harness is a folder with `system.md` (facts the solver is told), `method.md` (how to work) and `tools/` (code copied into its sandbox). Each one lives in `<name>/harness/`, with its README beside that folder, never inside it: anything inside changes the harness's fingerprint, and the RSI loop would then treat old runs as coming from a different harness.

Harnesses the RSI loop evolves stay with their loop, in `../rsi_loops/<loop>/candidates/hNNN/harness/`.

|---|---|---|---|

| `information_ladder/r1` to `r6` | see `information_ladder/README.md` | v0 plus one kind of extra information or tooling per rung (Chen's Oct 28 suggestions 1 and 3); generated by `../information_ladder/build_ladder.py` | `../results/information_ladder/`, run3 in `../rsi_loops/` (from r5) |

Run a harness with `HARNESS=harnesses/<name>/harness bash solver/run_solver_batch.sh ...` or start a loop from it with `--start`.
